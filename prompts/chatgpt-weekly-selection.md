# 每周选品会任务

使用 JOJO Creative Radar App，读取最新 weekly digest、趋势簇和候选机会卡。

最多选 3 个方向。每个方向至少追溯 3 条素材证据，并输出：

- 大盘可观察信号；
- 目标成人家长；
- 前 3 秒广告钩子；
- 广告外壳；
- 真实核心玩法；
- 20—90 秒首局循环；
- 可合理解释的教育构念；
- 两周竖切范围；
- 素材概念测试方法；
- 有效监护人 CPL 的证伪条件；
- 广告与实机一致性风险；
- 未成年人商业营销风险；
- 证据强度和缺失数据。

最终给出“进入素材概念测试 / 继续观察 / 暂停”建议，不直接建议完整开发。
